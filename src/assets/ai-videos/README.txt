AI VIDEOS / REELS — just drop your video files in THIS folder.

How it works:
- Put any video here: .mp4 .webm .mov
- It will AUTOMATICALLY appear in the "AI Videos" tab of the
  "Graphics & AI Video" section. No code editing needed.
- The video plays in a popup (lightbox) when clicked.
- The file name becomes the title.
  e.g.  ai-reel-1.mp4   ->  "Ai Reel 1"

Tips:
- Keep clips reasonably small (a few MB) so the site stays fast.
- Export reels/shorts as .mp4 for best browser support.
After adding files, restart the dev server (npm run dev) or rebuild.
